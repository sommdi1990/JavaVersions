# Java language examples by release

Four Maven projects collect small Java examples under release-labelled directories. The collection ranges from streams and optional values to sealed classes and virtual threads.

Read each example with its module configuration. The value-class exercise includes hand-written point and money types and equality examples. Its directory label alone does not establish that a feature is supported by a released JDK.

- [StreamsApiDemo.java](java8-project/src/main/java/com/example/features/StreamsApiDemo.java)
- [SealedClassesDemo.java](java17-project/src/main/java/com/example/features/SealedClassesDemo.java)
- [VirtualThreadsDemo.java](java21-project/src/main/java/com/example/features/VirtualThreadsDemo.java)
- [ValueClassesDemo.java](java25-project/src/main/java/com/example/features/ValueClassesDemo.java)
